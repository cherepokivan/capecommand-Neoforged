# Cape Command — Modrinth description

Cape Command adds a `/cape` command to Minecraft, allowing players to choose and display a custom cape from a large built-in catalog.

This NeoForge port supports Minecraft 1.21.1 and includes official Minecraft capes, event capes, community capes, and additional catalog entries. Use `/cape <name>` to equip a cape or `/cape reset` to remove it. The command provides in-game suggestions for all available capes, while capes marked as client-only require the Cape Command mod to be installed on the client.

## Features

- Simple `/cape <name>` command.
- `/cape reset` to restore the default skin cape.
- Automatic command completion.
- Server-side selection and client synchronization.
- Support for NeoForge 1.21.1.

## Commands

```text
/cape <cape_name>
/cape reset
```

Examples: `/cape copper`, `/cape moonlight_trail`, `/cape zombie_horse`, `/cape twisted`.
